# Архитектура Todo Application

## Repo alias
`main`

## Назначение репозитория
Todo List приложение — полный стек для управления задачами. Приложение состоит из двух репозиториев: `back` (Spring Boot REST API) и `front` (Next.js SPA).

**Backend** (`back` репозиторий) предоставляет REST API для CRUD операций над задачами, использует H2 database для персистентности и интегрируется с фронтендом через CORS. Работает на порту 8081.

**Frontend** (`front` репозиторий) предоставляет современный React-интерфейс для управления задачами, выполняется как Next.js SPA с Tailwind CSS стилизацией. Работает на порту 8082 и общается с backend через REST API (base URL: `http://localhost:8081`).

## Технологический стек
- **Framework**: Next.js 16.2.10 (App Router)
- **UI Library**: React 19.2.4
- **Styling**: Tailwind CSS 4
- **Language**: TypeScript 5
- **Runtime**: Node.js (port 8082)

## Архитектурные наблюдения

### 1. App Router с Client Components
Приложение использует современный Next.js App Router (app/ директория). Главный компонент `page.tsx` использует директиву `"use client"`, что означает клиентский рендеринг с полным доступом к React hooks (useState, useEffect).

### 2. REST API интеграция
Frontend общается с backend по REST API (HTTP/JSON). Base URL берётся из `NEXT_PUBLIC_API_URL` (по умолчанию `http://localhost:8081`). Реализованы CRUD операции для Todo сущности:
- GET /api/todos - загрузка всех задач
- POST /api/todos - создание новой задачи
- PUT /api/todos/{id} - обновление задачи
- DELETE /api/todos/{id} - удаление задачи

### 3. Оптимистичные обновления UI
Реализована стратегия оптимистичных обновлений: изменения применяются в UI немедленно, а запрос к API отправляется асинхронно. При ошибке UI откатывается к предыдущему состоянию. Это обеспечивает отзывчивый UX даже при сетевых задержках.

### 4. Централизованная обработка ошибок
Все API вызовы обёрнуты в try-catch блоки с единым подходом к обработке ошибок. При сетевых ошибках или проблемах с backend отображается красное сообщение об ошибке с подсказкой для пользователя.

### 5. Современный стек с темной темой
Tailwind CSS 4 используется с поддержкой dark mode (через `dark:` классы). UI адаптируется к системным настройкам темной темы. Стилизация использует переменные CSS (`bg-foreground`, `text-background`) для гибкой настройки цветовой схемы.

## Ключевые файлы

- `app/layout.tsx` - корневой layout приложения
- `app/globals.css` - глобальные стили и Tailwind
- `next.config.ts` - конфигурация Next.js
- `package.json` - зависимости и скрипты
