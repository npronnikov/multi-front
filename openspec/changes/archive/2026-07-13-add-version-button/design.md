# Design: Add Version Button

## Overview
Реализация кнопки отображения версии приложения через статический импорт версии из package.json. Кнопка будет добавлена в компонент главной страницы (page.tsx) рядом с заголовком "Todo List". При нажатии кнопка будет переключаться между отображением текста "version" и версии приложения.

## Decisions

### Decision: Использовать статический импорт версии из package.json
**Выбор:** Импортировать версию из package.json напрямую в компонент React
**Обоснование:**
- Минимальные изменения — только frontend, не требует модификации backend
- Простота реализации — нет необходимости создавать дополнительный endpoint
- Надёжность — версия всегда соответствует package.json, нет сетевых запросов
**Альтернативы:**
- Создание `/api/version` endpoint на backend — требует синхронизации версий и дополнительных изменений

### Decision: Расположение кнопки на главной странице (page.tsx)
**Выбор:** Разместить кнопку рядом с заголовком "Todo List" в компоненте page.tsx
**Обоснование:**
- Логическая связность — версия относится к приложению в целом
- Минимальные изменения — только один файл
- Соответствует текущей структуре — нет header/footer
**Альтернативы:**
- Создание header в layout.tsx — требует более значительных изменений структуры

### Decision: Переключение между "version" и версией при нажатии
**Выбор:** Использовать состояние (useState) для переключения между текстом "version" и версией
**Обоснование:**
- Простота UX — одно нажатие показывает версию
- Сохраняет минималистичный дизайн — нет popup/modal
- Легко реализовать с использованием React hooks
**Альтернативы:**
- Modal/tooltip — сложнее и менее минималистично

## Data Model
Изменений в модели данных нет. Версия считывается из package.json (строка "0.1.0").

## Implementation Notes

### Технические детали:
- **Фронтенд:** Next.js 16.2.10, React 19.2.4, TypeScript
- **Стилизация:** Tailwind CSS 4 (соответствует текущему дизайну)
- **Состояние:** React useState для управления отображением

### Паттерн реализации:
```typescript
// Импорт версии из package.json
import packageJson from '../../package.json'

// В компоненте
const [showVersion, setShowVersion] = useState(false)
const version = packageJson.version

// Рендер кнопки
<button 
  onClick={() => setShowVersion(!showVersion)}
  className="..."
>
  {showVersion ? `v${version}` : 'version'}
</button>
```

### Стилизация:
- Использовать существующие Tailwind классы для согласованности с дизайном
- Темная тема, минималистичный стиль
- Кнопка должна быть визуально похожа на другие UI элементы

## Risks
- **Риск:** Версия в package.json может не обновляться своевременно
  **Митигация:** Использовать версионирование по SemVer и обновлять package.json при релизах
- **Риск:** Кнопка может нарушить минималистичный дизайн
  **Митигация:** Использовать существующие стили и расположить кнопку гармонично
- **Риск:** Импорт package.json может не работать в некоторых конфигурациях Next.js
  **Митигация:** Проверить конфигурацию Next.js и использовать подходящий способ импорта (readFileSync или module resolution)
