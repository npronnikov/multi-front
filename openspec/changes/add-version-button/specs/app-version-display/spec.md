# App Version Display Specification Delta

## Purpose
Эта delta-spec добавляет возможность отображения версии приложения в UI. Пользователь может видеть номер версии приложения через кнопку в header и modal-окно с детальной информацией.

## Requirements

### ADDED Requirements

#### Requirement: Отображение кнопки Version в header
В header приложения должна быть кнопка с текстом "Version", которая предоставляет доступ к информации о версии приложения.

##### Scenario: Кнопка Version отображается в header
- **WHEN** Пользователь открывает главную страницу приложения
- **THEN** В правой части header отображается кнопка с текстом "Version"
- **AND** Кнопка имеет стиль, консистентный с другими UI элементами приложения
- **AND** Кнопка доступна для клика на desktop и mobile устройствах

##### Scenario: Стиль кнопки Version
- **WHEN** Пользователь просматривает приложение
- **THEN** Кнопка "Version" использует Tailwind CSS классы для консистентного стиля
- **AND** Кнопка имеет rounded corners
- **AND** Кнопка реагирует на hover (изменение цвета или opacity)

#### Requirement: Отображение информации о версии в modal
При нажатии на кнопку "Version" должно открываться modal-окно с информацией о версии приложения.

##### Scenario: Открытие modal с версией
- **WHEN** Пользователь кликает на кнопку "Version"
- **THEN** Открывается modal-окно по центру экрана
- **AND** Modal содержит заголовок "Application Version"
- **AND** Modal содержит информацию о версии frontend (например, "Frontend: 1.0.0")
- **AND** Modal содержит информацию о версии backend (например, "Backend: 1.0.0")
- **AND** Modal имеет кнопку закрытия ("X" в углу или кнопку "Close")

##### Scenario: Закрытие modal с версией
- **WHEN** Пользователь кликает на кнопку закрытия modal или вне области modal
- **THEN** Modal закрывается
- **AND** Пользователь возвращается к основному интерфейсу приложения

##### Scenario: Доступность modal на мобильных устройствах
- **WHEN** Пользователь открывает modal на мобильном устройстве
- **THEN** Modal корректно отображается на экранах маленького размера
- **AND** Modal можно закрыть стандартными жестами или кнопкой

#### Requirement: Источник версии приложения
Версия приложения должна быть определена на этапе сборки или конфигурации.

##### Scenario: Версия frontend определена
- **WHEN** Frontend приложение собирается
- **THEN** Версия frontend определяется из package.json (поле version) или из переменной окружения
- **AND** Версия хранится в константе или конфигурационном файле

##### Scenario: Версия backend определена
- **WHEN** Backend приложение запускается
- **THEN** Версия backend определяется из pom.xml (поле version) или из переменной окружения
- **AND** Версия доступна через API endpoint или хардкожена для начальной реализации

### REMOVED Requirements
Нет удаленных требований — это новая функциональность.
