# Proposal: Add Version Button

## Why
Текущее приложение Todo List не отображает информацию о версии. Пользователи не знают, какую версию приложения они используют, что может быть важно для:
- Отчетности при сообщении о проблемах
- Понимания функциональных возможностей
- Информированности об обновлениях

## What Changes
Будет добавлена кнопка "Version" в заголовок приложения (header). При нажатии будет отображаться модальное окно с информацией о версии приложения (включая номер версии frontend и backend).

## Capabilities
- `app-version-display`: Отображение версии приложения в UI с возможностью просмотра информации о версии через modal

## Impact
**Затронутые компоненты:**
- Frontend: Next.js page component (app/page.tsx)
- UI Layout: header section

**Риски:**
- Минимальные — добавляется только display-функциональность
- Не затрагивает существующую бизнес-логику
- Нет изменений в backend API

**Зависимости:**
- Нет внешних зависимостей

## Success Criteria
1. Кнопка "Version" отображается в header приложения
2. При нажатии открывается modal с информацией о версии
3. Версия отображается в читаемом формате (например, "Frontend: 1.0.0, Backend: 1.0.0")
4. Функциональность работает на desktop и mobile устройствах
5. Добавленный UI консистентен с существующим дизайном
