# Proposal: Add Version Button

## Why
В текущем приложении отсутствует отображение информации о версии, что затрудняет идентификацию установленной версии для пользователей и поддержки. Версия существует в package.json (0.1.0), но нигде не отображается в пользовательском интерфейсе.

## What Changes
Добавить кнопку "version" в пользовательский интерфейс приложения. При нажатии кнопка будет отображать текущую версию приложения, считанную из package.json. Кнопка будет расположена на главной странице рядом с заголовком "Todo List".

## Capabilities
- `ui-version-button`: возможность отображения версии приложения в UI через кнопку

## Impact
- **Затрагиваемые компоненты:** Frontend (Next.js, React), файл page.tsx
- **Пользователи:** Все пользователи приложения получат возможность видеть текущую версию
- **Риски:** Минимальные — только frontend-изменения, не затрагивает backend
- **Зависимости:** Нет

## Success Criteria
- Кнопка "version" отображается на главной странице рядом с заголовком
- При нажатии кнопки отображается текущая версия из package.json
- Визуальный стиль соответствует минималистичному дизайну приложения
- Функциональность работает без ошибок в браузере
